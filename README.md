# RC3 AI Hackathon 2026

My solutions for the RC3 AI Hackathon (Riphah, 5 November 2026).

| Folder | Task |
|---|---|
| `task1/` | Task 1: project brief → Jira tickets (LLM pipeline, CSV/JSON export, tests) |
| `task2/` | Task 2: near-duplicate documents with MinHash + LSH (Jaccard ≥ 0.8 on 5-word shingles) |
| `task4/` | Task 4 Track B: GitHub repository analyzer CLI |
| `task4_trackA/` | Task 4 Track A: automated PR reviewer (ticket → diff → LLM verdict → block or merge) |

Each folder has its own `README.md`, and `task4_trackA/RUN.md` lists every command.

## Not in this repo
- **Secrets:** no `.env` or `.env.example` files are committed. Set the API keys as environment variables (see each task's README).
- **Organiser material:** the datasets, answer keys, generator scripts and handbook belong to the organisers and are not published.
- **Chat exports:** one GitHub token pasted during the session is replaced with `[REDACTED]`.
